# Forever Quest Journal

A clean, zone-by-zone quest journal for **World of Warcraft: Forever**, styled
to sit naturally beside Forever Dungeon Journal.

## Features

- Browse quests by zone through a two-column landscape gallery.
- English and French interface and quest content.
- Per-character Finished and Unfinished tracking.
- A distinct in-quest-log marker for quests the current character has accepted.
- Quest prerequisites and next-in-chain information.
- Possible quest reward items with in-game item tooltips.
- Quest giver, object, or starting-item information.
- Place a waypoint for a quest's starting location.
- Search zones and quest names.
- Mean, median, and minimum–maximum quest-level summaries for each zone.
- Previous/next zone navigation and a draggable minimap launcher.
- Can remain open alongside Forever Dungeon Journal.

The bundled database currently contains 3,977 quests across 48 populated
zones.

## Installation

1. Download `ForeverQuestJournal-1.4.0.zip` from the latest release.
2. Extract it into your WoW Forever `Interface/AddOns` directory.
3. Confirm that the final path is `Interface/AddOns/ForeverQuestJournal`.
4. Restart the game or enter `/reload`.

Open the journal from its minimap button, the AddOn Compartment, or with:

```text
/fqj
```

## Compatibility

- WoW Forever interface version: `16001`
- Saved progress is stored per character.

## Data and artwork

Quest data was generated from QuestieDB's Forever dataset and French
localization. Zone cards use uniformly prepared World of Warcraft zone
screenshots from the Wowpedia archive. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)
and [Media/Zones/SOURCES.txt](Media/Zones/SOURCES.txt) for details.
